🔐 Authentication APIs

POST
/auth/register/send-otp
Public

Description

Send OTP to mobile number for citizen registration.

Authorization

Not Required

Request Body

{
  "phone":"9876543210"
}

Success Response

{
 "success":true,
 "message":"OTP sent successfully."
}
POST
/auth/register/verify-phone
Public

Description

Verify OTP and receive registration token.

Request Body

{
 "phone":"9876543210",
 "otp":"123456"
}

Response

{
"registrationToken":"JWT_TOKEN"
}
POST
/auth/register/complete

Description

Create new account after OTP verification.

Request

{
"registrationToken":"JWT_TOKEN",
"pin":"1234",
"ward":2,
"role":"citizen"
}
POST
/auth/login/pin

Description

Login using phone number and PIN.

Request

{
"phone":"9876543210",
"pin":"1234"
}

Returns

{
accessToken:"",
refreshToken:"",
user:{}
}
POST
/auth/forgot-pin/send-otp

Description

Send OTP for resetting PIN.

{
"phone":"9876543210"
}
POST
/auth/forgot-pin/verify-otp
{
"phone":"9876543210",
"otp":"123456"
}
POST
/auth/forgot-pin/reset-pin
{
"resetToken":"JWT_TOKEN",
"newPin":"5678"
}
POST
/auth/refresh-token

Generate new Access Token using Refresh Token.

POST
/auth/logout
JWT Required

Logout current user and invalidate refresh token.

/users/deputies

Description

Authorization

Bearer Access Token

Request Body

{
"phone":"9876543210",
"pin":"1234",
"ward":3,
"permissions":[
"create:officials",
"edit:schemes",
"transfer:councillor"
]
}

Success Response

}

/users/officials

Request Body (Service Officer)

"department":"Water Supply"

}

/users/councillors/:id/transfer
MLA Permission : transfer:councillor

Description

}

}
